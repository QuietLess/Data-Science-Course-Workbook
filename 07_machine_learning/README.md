# 07 — Machine Learning

Makine öğrenmesi algoritmaları ve modelleme.

## Konular (Topics)

### Machine Learning Pipeline
- **Train-test split** - Veri ayırma
- **Cross validation** - Çapraz doğrulama
- **Model evaluation metrics** - Model değerlendirme metrikleri

### Algoritmalar

#### Regression
- **Linear Regression** - Doğrusal regresyon
- **Logistic Regression** - Lojistik regresyon

#### Tree-based Methods
- **Decision Trees** - Karar ağaçları
- **Random Forest** - Rastgele orman
- **Gradient Boosting** - Gradient boosting

#### Distance-based Methods
- **KNN** - K-Nearest Neighbors
- **SVM** - Support Vector Machine

#### Probabilistic Methods
- **Naive Bayes** - Naive Bayes sınıflandırıcı

### Advanced Topics
- **Hyperparameter tuning** - Hiperparametre ayarlama
- **Feature importance** - Özellik önem sırası
- **Model interpretation** - Model yorumlama
