# 02 — Python Programming for Data Science

Veri bilimi için Python temelleri.

## Konular (Topics)

- **Python syntax** - Python'un temel söz dizimi
- **Variables** - Değişkenler ve veri türleri
- **Data structures** - Veri yapıları
- **Lists** - Listeler
- **Dictionaries** - Sözlükler
- **Tuples** - Tuple'lar
- **Sets** - Kümeler
- **Functions** - Fonksiyonlar ve tanımlama
- **Loops** - Döngüler (for, while)
- **Conditional statements** - Şartlı ifadeler (if, else, elif)
- **List comprehensions** - List comprehensions ve generator expressions
- **Pythonic programming** - Pythonic kod yazma teknikleri
